## 🛠️ Recording Checklist & Best Practices

1. **Local Server Verification:**
   - Frontend running on: `http://localhost:5173`
   - FastAPI Backend running on: `http://localhost:8000`
2. **Audio Setup:**
   - Use a good USB microphone or headset.
   - Keep system audio enabled at ~50% so the browser's **"🔊 Listen"** speech playback is clearly heard in Scene 5.
3. **Pacing:**
   - Avoid frantic mouse movements; move deliberately from element to element.
   - Pause for half a second after each click to allow the animation to register before speaking.
4. **Recommended Screen Recording Tools:**
   - **OBS Studio** (Free, open source, supports mic + desktop audio separation)
   - **Windows Game Bar** (`Win + Alt + R` to record current window)
   - **Loom** (Instant cloud shareable link)
